# Known Issues

- **Orchard-to-Ironwood spend untested against real note.** Regtest activates NU6.3 and NU7 simultaneously at block 2, preventing pre-activation Orchard note creation. Testing Orchard-to-Ironwood turnstile migration requires adjusting Zebra and consensus activation heights. (see p4_followup_orchard_funding.log)
- **Empty-wallet Ironwood anchor check only mock-tested.** Zebra never reports an empty Ironwood tree because the block 2 coinbase creates an Ironwood output. The empty-node send path is covered by mocks, though the empty Orchard root matches our constant. (see ironwood_empty_root.log)
- **SDK send tests mock Halo 2 proving.** Unit tests stub transaction proving to isolate balance reservation, anchor selection, and fee calculations. Cryptographic proving execution is exercised separately in Rust integration tests and live regtest runs.
- **Zaino experimental tier on unreleased branch.** Zaino runs unreleased branch `feat/nu7` (pin `aaf8122a`, checked 2026-11-18), not merged into `dev` (last release 0.10.2). It is regtest-only, takes ~525 s on first build, uses plain-text gRPC, and operates via RPC backend (direct mode is spike-only).
- **Zallet beta.4 memo parsing and RPC limitations.** `z_listtransactions` fails with `InvalidUtf8` on non-UTF-8 memos (#794); fixed on `main` by PR #943 (merged 2026-11-16), but unreleased (latest tag v0.1.0-beta.4, checked 2026-11-18). Standard `listtransactions` is omitted (only `z_listtransactions` is available).
- **Stock Zebra 7.1.0 omits indexer feature.** The `zfnd/zebra:7.1.0` Docker image (digest `sha256:4f9536c8…`, checked 2026-11-18) lacks the Cargo indexer feature. On regtest, Zallet beta.4 funds and spends transparent UTXOs identically; testnet, mainnet, long transparent history, multiple accounts, and native macOS outside Docker remain NOT TESTED. (see trial_zallet_transparent_stock.log)
- **Testnet initial wallet sync duration.** A fresh wallet sync on public testnet takes ~22.6 minutes for 408,475 blocks (measured 2026-10-26 on v0.1.0-alpha against `testnet.zec.rocks`; not re-measured on lightwalletd v0.6.2). Transient stream drops require client retry handling. (see wallet_b_first_sync.log)
- **Upgrading from alpha.4 or earlier requires wipe.** Regtest ports, volumes, and network metadata changed in alpha.5. Upgraders must run `zcash-dev regtest wipe --yes` and delete old SQLite wallet databases before starting new stacks.
- **Unexplained note count match in coexistence run.** Zallet and the SDK both report exactly 110 unspent notes during coexistence runs. The exact set match across pools remains unexplained without captured per-note transaction dumps. (see zaino_zallet_coexistence.log)
- **No recorded live mainnet read-only checks.** Live read-only queries against mainnet nodes have not yet been recorded in test logs. Mainnet branch ID (`0x37a5165b`) and transaction expiry rules are unit-tested; live recordings cover testnet and regtest only.

For detailed diagnostic traces, consensus citations, and historical spike notes, see `docs/dev/known-issues-evidence.md`.
